这套东西是什么

没装后端，账号在你自己的电脑里
账号存在哪

存在 thirdserver\users.json 里，跟这台电脑上的启动器放一起。没有云端、没有第三方转发，换电脑要自己把文件带过去。

接口是什么

标准 Yggdrasil：注册、登录、刷新、校验、角色查询五个端点。/api/yggdrasil、/api/authlib-injector 和空根路径都指向同一套。

谁能连上

只有同一个局域网里的设备能直连（手机、另一台电脑）。跨网要用端口映射或内网穿透，把 8080 暴露出去，并且建议套一层 HTTPS。

常见卡住的地方

按顺序排
点「连接」提示连不上

三种可能：服务没跑（在工程目录执行 python thirdserver\omc_auth_server.py）、地址端口写错（默认 8080）、或者防火墙拦了。先在电脑上开个命令行跑 curl http://127.0.0.1:8080/api/yggdrasil 看有没有返回 JSON。

页面提示「https 不能连 http」

GitHub Pages 走的是 https，浏览器不允许 https 页面去请求 http 接口（混合内容）。三个解法：把本文件下载到本地双击打开；用启动器里登录；或者给服务套一层 HTTPS 反向代理再填 https 地址。

注册提示用户名已存在 / 邮箱已注册

同一个用户名和邮箱只能注册一次。忘记了就直接拿另一个名字注册，或者去 users.json 里把那条记录删掉再重来。

登录成功但进游戏提示验证失败

看启动器里填的地址是不是这台电脑当前的局域网 IP——换了 WiFi 之后 IP 会变，服务没重启但地址变了。启动器控制台会打出「局域网/别的机器填：http://x.x.x.x:8080/api/yggdrasil」，照着填。

accessToken 多久过期

三十小时。过期后启动器会自动 refresh 续期；refresh 也失败就得重新登录一次。
